# 한국 날씨에서 살아남기 (K-Weather Survival Runner)

사계절 내내 몰아치는 한국의 기상 재난(미세먼지, 꽃샘추위, 폭염, 장마, 태풍, 북극한파)을 점프와 슬라이드로 피하며 달리는 모바일 중심 2D 픽셀 러닝 게임입니다.

## 주요 특징
- **사계절 동일 비율 무한 순환:** 봄 → 여름 → 가을 → 겨울이 반복되며, 1년이 지날수록 속도와 기상 장애물 난이도가 상승합니다.
- **6종 K-날씨 캐릭터:** 기본 모험가, 얼죽아(스키어), 반팔충(한복 소년), 패딩 대원, 우비 소년, 산타복(패션 피플)
- **골드 & 상점 시스템:** 달리며 모은 골드로 캐릭터 해금, 영구 능력치 강화(체력·자석·방어·점수), 출발 아이템 구매 가능
- **FEVER 모드 & 강아지 펫:** 코인과 황금 별을 모아 FEVER 무적 질주 발동!

## 조작법
- **모바일:** 화면 하단 `점프(2단 점프)` / `슬라이드(꾹 누르기)` 버튼 터치
- **PC:** `Space` / `↑` / `W` (점프·2단 점프), `↓` / `S` (슬라이드), `Esc` (일시정지)
